# 重返长征路

《重返长征路》以少年小二娃寻找亲人的旅程为线索，让玩家走进中央红军长征初期的历史
环境。小二娃从战火后的村庄出发，在救出二虎、寻找粮食和水源、救护伤员、帮助群众
兑换苏币、向医疗点运送物资的过程中，逐渐理解红军为什么能够得到人民支持，并最终
选择与队伍一同前行。

这段故事的意义不只在于回望一条行军路线，更在于把长征精神落到一次次具体选择中：
自己身处困境时是否仍愿意帮助别人，资源有限时能否准确承担责任，面对危险和困难时
是否继续前进。游戏通过“友谊、相遇、团结”三章，呈现人民立场、理想信念、严明纪律、
团结互助和责任担当，让爱国主义教育从文字结论转化为可以参与和体会的行动。

> 游戏中的小二娃、二虎等人物经历属于叙事创作；时间、地点与历史收藏用于连接真实
> 历史背景。游戏是认识长征的入口，不替代教材、档案或专业历史研究。

## 故事与玩法

原版章节界面确实规划了 11 张卡片，但这不代表 APK 内已有 11 个完整关卡：只有前三张
卡片带有故事正文和开场数据，实际随 APK 发布的可加载内容是三章、七张地图。当前维护版
完整保留并测试了这七张地图，同时阻止缺少地图资源的后续占位进入黑屏。原作规划名称
“离别、手足、先锋、死战、奇缘、奉献、神农、决胜”仍作为历史资料保留，没有用杜撰
剧情冒充原作。

七张已发布地图包括：

- 第一章“友谊”：在被战争破坏的村庄中救人、寻找食物、取水灭火；
- 第二章“相遇”：穿越战场、救护红军伤员，并在群众帮助下制作取水工具；
- 第三章“团结”：来到白石渡，寻找群众失物、兑换苏币、运送并分发医疗物资。

手机或模拟器可轻触道路让角色走向目标；键盘可使用 `A`、`D` 或左右方向键移动，在
梯子上使用 `W`、`S` 或上下方向键。角色接近人物或物品后，点击出现的操作按钮进行
对话、拾取或交付。主菜单的“章节”入口支持从任意已发布地图开始，便于课堂选学、
补收集和回归测试，同时不改变首次顺序通关的故事结构。

## 维护版改进

本项目由原版 APK 的 Cocos Creator 2.4.3 内容恢复并迁移至 Cocos Creator 2.4.15，保留
原作场景、美术、音频、动画、配置和 JavaScript 玩法逻辑。维护版在尊重原作叙事与
交互尺度的基础上，完成了以下改进：

- 修复过场动画和 NPC 骨骼附件错位、缺失及切场释放异常；
- 恢复动态片头、背景音乐、动作音效、语音和角色脚步声；
- 统一横屏、安全区、宽屏 HUD、弹窗和任务卡片布局；
- 修复前后景入口切换后的摄像机层级、边界和角色跟随；
- 恢复原作近身碰撞交互范围，并排除兑换员前方的错误阻挡；
- 修复任务完成后道具残留、拾取与交付错序、第二章出口等流程问题；
- 增加自动存档、损坏存档恢复、旧存档迁移和七关任选；
- 保留原版应用图标，仅发布 `arm64-v8a`，并保持 Android 离线零权限运行。

## 工程维护原则

- 场景、预制体、动画、图片、音频、Spine、DragonBones 数据和史实配置均来自原版资源；
- 尊重原作玩法和叙事，保留经过验证的稳定性、适配性与操作体验修复；
- 配置 ID、Cocos UUID 和存档键保持兼容，避免升级破坏既有进度；
- 归档恢复材料只用于溯源，日常维护使用可读命名后的源码与资源；
- APK、AAB 和本地签名材料属于可重复生成或敏感产物，不纳入版本控制。
