# 《重返长征路》玩家通关攻略

适用版本：1.2.0（三章、七张地图，仅支持 arm64 Android 设备）

剧透提示：本文包含完整任务顺序、两组答题答案和结局说明。

## 1. 先看操作

- 点击道路或地面：角色走向点击位置。
- `A` / `D` 或左右方向键：向左、向右移动。
- `W` / `S` 或上下方向键：在梯子上移动。
- 走到人物或物品旁并与其接触：右下角会出现带目标名称的操作按钮，点击它完成拾取、
  交谈、交付等动作。维护版已恢复原作近身碰撞范围，隔着较远距离不会触发。
- 点击人物旁的手势气泡：也可以触发对应交互。
- 对白中第一次点击：立即显示完整句子；再次点击：进入下一句。
- CG 或章节演出：按画面提示点击屏幕或“跳过”按钮，可直接进入后续环节。
- 点击顶部“当前目标”：可重新查看本地图提示。
- 主菜单点击“章节”可任选三章中的七个已发布关卡；向左拖动路线图查看后面的卡片，
  选中后核对右侧章/关和地图名，再点“进入关卡”。
- 游戏会在手机上强制横屏；启动后请保持手机横向，等待画面完成一次方向调整再操作。
- 移动时会听到走路或跑步脚步声，停下后脚步声也会停止。
- 暂停菜单的设置页可分别调整背景音乐、音效和语音；脚步、拾取、取水、开门和枪炮属于
  “音效”。

剧情演出期间角色会暂时不能移动。等对白、镜头或动作结束，顶部任务条重新更新后再操作。

## 2. 通关时最重要的规则

1. 先看顶部“当前目标”，箭头表示目标大致在左侧或右侧。
2. 必须走到足够近，右下角显示“拾取【物品】”“交给【人物】”后再点。
3. 一次只能携带一件任务物品。先交掉手里的东西，再取下一件。
4. 拿错物品不会被没收。提示会同时告诉你目标需要什么、你当前拿着什么。
5. 有些任务要在地图之间往返。当前地图没有目标时，回到门口检查相邻地图。
6. 拾取、对话、答题、投递和跨图后都会自动保存；退出再进通常可以从最近状态继续。
7. 收藏品和史实是可选内容，不影响主线结局。

## 3. 第一章：友谊

这一章的核心是救出二虎、寻找食物、取水并离开村庄。

### 3.1 村庄主路

1. 片头结束后，沿道路向右走。
2. 到土墙废墟附近会听到求救声。完成小二娃和被困者的对白。
3. 在废墟附近找到铁锹，靠近后点击“拾取【铁锹】”。
4. 回到被困者旁，对废墟使用铁锹，把二虎救出来。
5. 根据任务提示寻找生红薯，拾取后前往火堆。
6. 第一次点击火堆开始计时。观察蓝色“生”、绿色“熟”、红色“焦”的时机区，指针
   进入绿色区间后再次点击。
7. 拾取熟红薯并交给二虎。生红薯或烤焦的红薯不能完成这一步，重新找一只再烤即可。
8. 进入相邻的取水支路，找到空水桶，然后返回主路。
9. 拿空水桶到取水点，操作后会变成有水的桶。
10. 按当前目标把水用于指定火堆或道路障碍。连续泼水三次才能扑灭；两次之间不要停留
    超过 20 秒，否则火势会恢复一级。
11. 障碍解除后继续沿道路前进，在出口触发章节结算。

如果右下角没有操作按钮，继续向物品或人物靠近一点。任务卡、物品卡打开时，先把卡片
关掉再移动。

### 3.2 取水支路

这张小地图与村庄主路相连：

1. 进入后沿路寻找空水桶。
2. 拾取水桶后原路返回。
3. 路上可以拾取可选收藏`红军临时借谷证`。

### 3.3 第一章收藏

本章共有四件可达收藏：

| 收藏 | 大致区域 |
|---|---|
| 经济建设公债 | 村落废墟 |
| 《为开展查田运动》 | 村落水井附近 |
| 红军临时借谷证 | 取水支路沿途 |
| 《中国工农红军优待条例》 | 村屋附近 |

收藏卡弹出后看完说明并关闭即可，不需要把收藏交给任何人。

## 4. 第二章：相遇

这一章要救助昏迷的红军战士，取得饮水，并跟随队伍完成战场撤离。

### 4.1 战场主路

1. 跟着道路和枪炮声前进，完成小二娃、二虎的对白。
2. 找到昏迷的红军战士，触发寻找饮水的任务。
3. 沿当前目标前往村屋水源地图。
4. 在支路完成老农答题、取得柴刀、制作竹筒并装水。
5. 带着装满水的竹筒回到红军战士身边，点击交付。
6. 战士醒来后继续跟随剧情和队伍前进。
7. 战场演出自动进行时等待镜头结束；出现可操作按钮时按提示移动或操作。
8. 完成冲锋、敌人撤离和胜利对白，继续到结算点进入第三章。

### 4.2 村屋水源

#### 老农三题答案

| 题目 | 正确答案 | 选项 |
|---|---|---|
| 中央苏区成立时间是什么时候？ | 1931年11月7日 | 第 3 项 |
| 中央苏区成立后，国民党一共发动了几次围剿？ | 5次 | 第 2 项 |
| 红军的全称是什么？ | 中国工农红军 | 第 1 项 |

答错后会显示正确答案和史实解释，只需要重答当前题。

#### 取水步骤

1. 与老农交谈并答对三题。
2. 找到柴刀并拾取。
3. 对竹子使用柴刀。
4. 拾取砍下的空竹筒。
5. 带竹筒前往水源，点击取水。
6. 确认手中的物品变成装满水的竹筒。
7. 原路返回战场主路，把水交给昏迷的战士。

地图有高低层和楼梯。人物走到楼梯口时，使用上下方向键或点击可到达的道路位置；如果
人物被枯树挡住，先看当前任务是否要求从另一层绕行。

| 红军绑腿 | 战场后方 |
| 红军干粮袋 | 补给区域 |

## 5. 第三章：团结

第三章往返较多。主线顺序是：

```text
找蓝布包线索
→ 到小学堂揭露小偷
→ 返回主路并参军换装
→ 医疗点第一轮分发
→ 找政委申请补给
→ 小学堂领取物资箱
→ 医疗点第二轮分发
→ 返回主路结算
```

### 5.1 找回蓝布包

1. 在白石渡主路继续前进，与哭泣的大妈交谈。
2. 记住她说的三条线索：
   - 四枚二角硬币；
   - 一张五元苏币；
   - 三张一元苏币。
3. 从主路进入医疗点，再从医疗点通往小学堂兑换点。
4. 与拿着蓝布包的人交谈，确认他的说法可疑。
5. 找兑换员说明情况，开始三题核对。

兑换员必须近身交互。沿道路走到兑换员面前、看到右下角动作名称后再点；不要站在小学堂
中央远距离连续点操作键。维护版已经移开兑换员身后的旧阻挡区，角色可以正常贴近。

#### 蓝布包三题答案

| 题目 | 正确答案 | 选项 |
|---|---|---|
| 包里面有几枚二角硬币？ | 四枚 | 第 2 项 |
| 包里面有几张五元苏币？ | 一张 | 第 3 项 |
| 包里面有几张一元苏币？ | 三张 | 第 2 项 |

6. 三题答对后完成揭露小偷的剧情。
7. 返回白石渡主路，与大妈、二虎和王守仓继续交谈。
8. 完成加入红军和更换军装的剧情。

忘记线索也不用重开游戏：返回主路再和大妈交谈，她会重复蓝布包内容。

### 5.2 医疗点第一轮：四次分发

1. 穿上军装后到医疗点，与赵亦涵医生交谈。
2. 医生开始给工人看病，你负责从旁边箱区拿药。
3. 第一轮一共需要：
   - 中药药包 1 次；
   - 西药药瓶 1 次；
   - 绷带 2 次。
4. 每次先看顶部目标或右下动作标签，再拿对应物品交给当前患者。
5. 完成后进度应达到 `4/4`。

箱子和患者离得很近时，不要只凭位置猜。拿起物品后，系统会优先显示匹配它的接收者；
走到医生/患者旁，等按钮变成“交给【目标】”再点。

### 5.3 申请并运送物资

1. 第一轮结束后返回白石渡主路。
2. 与政委交谈，申请新的物资和药品。
3. 前往小学堂兑换点，找到可拾取的物资箱。
4. 拿着物资箱回到医疗点。
5. 把物资箱交给赵医生。交付成功后，新的物品箱和第二批患者会出现。

### 5.4 医疗点第二轮：五次分发

第二轮一共需要：

- 衣物 2 次；
- 银元 1 次；
- 西药药瓶 2 次。

按顶部目标逐个完成，进度达到 `5/5`。拿错时不会损失物品：

1. 记住提示里的“需要【……】”；
2. 回箱区找到正确物品；
3. 再靠近接收者交付。

九次总分发完成后，与赵医生完成结尾对白。

### 5.5 第三章结局

1. 从医疗点返回白石渡主路。
2. 找到王守仓并完成最后对白。
3. 章节摘要会显示本节已获得的收藏和史实数量。
4. 提示中的“可返回探索”表示遗漏的收藏或史实仍可从第三节队伍驻地继续寻找，不影响
   主线已经通关。
5. 点击“确定”，游戏返回主菜单；这就是当前版本的主线通关。

### 5.6 第三章收藏

七张已发布地图中有五件可达收藏：

| 收藏 | 大致区域 |
|---|---|
| 红军八角帽 | 白石渡行军道路 |
| 中革军委颁发的红军编制表 | 队伍驻地区域 |
| 医疗箱 | 医疗点 |
| 二角硬币 | 小学堂/营地附近 |
| 红星报 | 小学堂兑换点的主线路径 |

`红星报`位于从医疗点进入小学堂后的必经道路附近。拾取五件后，第三章可以达成收藏
`5/5`。

## 6. 常见卡关处理

### 6.1 人物不能移动

按顺序检查：

1. 是否正在播放对白、CG、镜头移动或角色动作；
2. 是否有任务卡、物品卡、答题或暂停弹窗没有关闭；
3. 点击的是道路，不是顶部任务条、世界气泡或右下操作按钮；
4. 尝试 `A` / `D` 或左右方向键；
5. 等两秒让场景加载完成，再尝试移动；
6. 退出到系统桌面后重新进入，读取最近自动存档。

### 6.2 人物在画面边缘

先点击人物面前的道路，让镜头重新跟随。不要连续点击画面最外侧的 UI 安全区。若处于
楼梯地图，先回到当前层的水平道路，再决定上下移动。通过门或道路进入前后景后，镜头会
自动移动到人物所在层；等淡入结束再点击，避免把过渡动画误当成卡住。

### 6.3 看得到物品但捡不起来

1. 走到物品正下方或旁边；
2. 等右下角显示“拾取【物品名】”；
3. 点击右下操作按钮或物品旁手势气泡；
4. 如果手里已经拿着别的任务物品，先完成交付。

任务操作只在角色真正接触目标后出现。地图上看得到目标但按钮尚未出现，不代表存档损坏；
继续沿可行走道路靠近即可。道路点击和右下操作键区域已经分开，远处点击不会替你执行任务。

### 6.4 卡片太大或挡住操作

卡片本身是弹窗状态。先点卡片的确认/关闭区域，不要隔着卡片点击道路。关闭后任务条和
操作按钮会重新出现。

### 6.5 交给人物没有反应

看提示中的两行信息：

```text
需要【目标物品】
当前【手持物品】
```

两者不一致时回箱区换正确物品。错误交付不会消耗手上的物品。

### 6.6 不知道下一步去哪

1. 看顶部目标和左右箭头；
2. 点击顶部目标重新打开本地图提示；
3. 检查最近经过的人物是否出现新气泡；
4. 检查相邻地图的门；
5. 第三章尤其要在主路、医疗点、小学堂之间往返。

### 6.7 没有背景音乐、脚步或动作音效

1. 打开暂停菜单的设置页，确认“背景音乐”和“音效”已开启且不是 0%；
2. 背景音乐与音效是两组设置，只听不到脚步时优先检查“音效”；
3. 回到游戏后先停下，再重新点击道路，脚步声会随下一次移动开始；
4. 检查手机的媒体音量和勿扰/静音状态；
5. 切到系统桌面再返回游戏，音乐会按当前章节恢复；
6. 不要为了恢复声音直接卸载，卸载会清除本机进度。
