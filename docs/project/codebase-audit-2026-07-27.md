# 《重返长征路》综合代码与章节审计

日期：2026-07-27  
范围：三章七张可玩地图、60 个运行脚本、Android 原生构建、存档与恢复、交互体验、资源生命周期和模拟器回归。

## 结论

当前项目的三章主线已可通关。本文件最初记录的正式发布门槛和 P0/P1/P2 建议均已在
`codex/implement-full-audit` 分支实施；详细对应关系、验证证据和唯一剩余的外部设备门禁见
[`audit-implementation-2026-07-27.md`](audit-implementation-2026-07-27.md)。

实施后的工程已具备两代原子存档、章节 Asset Bundle、2048 纹理预算、事件驱动任务追踪、
生产包裁剪、统一日志、自动配置/契约校验，以及基于 AGP 8.9.2、Gradle 8.11.1、JDK 17、
targetSdk 36 的签名 APK/AAB 流程。APK/AAB 是本地可重复生成产物，始终由 `.gitignore`
排除，不进入版本库。

## 本轮已完成

### 操作与可玩性

- 携带物资时，匹配当前任务的接收者优先于附近箱子，距离仅用于同优先级目标的裁决。
- 送错物品时显示“需要什么、当前携带什么”，不再只写调试日志。
- 七张地图的提示改为当前地图相关的可执行目标，移除无关的“帮助老奶奶过马路”占位内容。
- 场景 CG 增加“点击屏幕跳过”，并保留原结束回调，避免跳过后任务链中断。
- 普通对白逐字速度由 90ms/字调整为 55ms/字，仍支持点击立即显示整句。
- 章节收藏/史实详情显示真实已获得数量；修正第二节总数 `4|3` 为 `3|4`。

### 存档与稳定性

- 交互、对话、答题、CG 和物品事件完成后合并自动存档；Android 进入后台时强制保存。
- 移动落点存档改为 750ms 合并写，减少连续短距离移动产生的写放大。
- 章节重玩和正常结局只清理当轮场景状态，不再短暂删除永久收藏、史实和章节解锁数据。
- `longmarch`、`tempData`、`cross`、`heroItem`、`heroFollow` 增加损坏 JSON 容错；非法章节值有限值校验并限制到已发布章节。
- 地图、主角、物件和配置加载失败增加空值保护；章节资源失败会重试一次，并允许返回主菜单。
- 修复 BGM 异步竞态、关闭后无法重新开启、音频 ID 为 0 时无法停止，以及快速重复音效叠播。
- 场景销毁时解绑键盘、Canvas、按钮、全局触摸和后台事件，并释放 RenderTexture。
- Android 日志检查新增 Native 崩溃、ANR、tombstone 和未捕获异常关键字。

### 性能

- 删除场景启动时约 4.72MiB 的无效像素数组、约 123 万次循环和随后立即被覆盖的纹理上传。
- RenderTexture 画面复用单个 SpriteFrame，消除过场期间约每秒 20 个 SpriteFrame 的持续分配。
- 静止镜头不再每帧重复写十组视差层变换。
- 云和道路更新降为 30fps，并用 `dt` 补偿保持原速度。
- 落叶节点离场时销毁，异步加载回调增加场景存活检查。
- DragonBones 尚未加载完成时暂停/恢复不再空引用。

## 原审计待办（现已实施）

### P0：正式发布门槛

1. **现代 Android release 工程**
   - 当前产物仍是 debug APK、Debug 签名、targetSdk 28。
   - 需要升级 Gradle/AGP/JDK/target SDK，建立正式签名、versionCode、AAB、zipalign 和产物自动校验。

2. **章节资源分包与大纹理**
   - `scani3_tex.png` 为 4096×4096，RGBA 展开约 64MiB；另有约 4031×2710 的大纹理。
   - `loadDir` 后对目录字符串调用 `cc.resources.release` 实际不能释放整个目录。
   - 建议按章节拆 Asset Bundle，atlas 控制在 2048 内，并配置 ETC2/ASTC 等设备纹理格式。

3. **原子存档**
   - 当前兼容旧 checkpoint 的多键存档仍可能在进程被杀时形成不同 revision 的组合。
   - 建议新增单键 `longmarch_save_v2`，包含 `schemaVersion`、`revision`、完整状态和 `current/previous` 两代快照；过渡期双写旧键。

### P1：体验与内容

1. 将当前地图提示升级为“未完成事件驱动”的任务追踪，显示目标、方向、所需物品与完成进度。
2. 第三章连续九次物资往返重复度偏高；前两次保留完整教学，后续可增加分发托盘或交付后自动返回箱区。
3. 烤红薯小游戏增加生/熟/焦圆环区间和首次操作提示。
4. 答题错误后显示正确答案与史实解释，并只重试当前题。
5. 首次通关后提供缺失收藏的大致区域提示；结局显示史实与收藏完成摘要。
6. 操作按钮旁增加当前目标名称，例如“交给赵医生”“拾取衣物”。

### P2：维护与测试

1. 建立配置图校验：检查所有 `next`、door、talk、plot、item、cross 引用，不可达节点和无出口循环。
2. 从生产包排除旧编辑器、废弃热更新和未使用网络逻辑。
3. 发布版通过统一日志门面关闭普通日志，只保留章节、地图、事件 ID 和错误上下文。
4. 增加自动化契约：移动、拾取、送错/送对、弹窗遮挡、换图、交互后强杀、后台恢复和损坏存档。
5. 增加真实 ARM64 设备的冷启动、连续换章、后台恢复和 30 分钟稳定性测试。
6. 当前仓库尚无基线 commit；下一轮结构性改造前应建立可回滚基线。
